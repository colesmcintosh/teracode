# Changelog

All notable changes to TeraCode are documented here.

## 0.1.0 - 2026-08-17

- Added the switchyard TUI with doctor, blueprint, policy, live run, result, and history stages.
- Added provider-neutral planning contracts and six built-in coding-agent CLI adapters.
- Added bounded DAG execution, run-scoped Agent Skills, normalized event streams, retries, and process-group cancellation.
- Added explicit workspace and autonomy policies, isolated Git worktrees, overlap detection, binary patch assembly, and staged integration output.
- Added acceptance-driven validation, bounded rework, local SQLite history, retention, export/delete, and reusable factory blueprints.
- Added fixture-based tests, fake process supervision, temporary Git integration tests, compact TUI snapshots, and macOS/Linux CI.
